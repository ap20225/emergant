## Original user mission

The user described the previous agent as dropshipping-oriented; inspection found only a generic OpenClaw hosting/setup app, without dropshipping-specific code or collections.

"Find legitimate software-development opportunities and coding bounties, evaluate them economically, autonomously research and implement qualified opportunities, test and review the resulting code, prepare pull requests, track outcomes and payments, and progressively improve its bounty-selection strategy."

### Non-negotiable principles
- Start with $0 capital and $0 authorized model/tool spending. Optimize VERIFIED NET PROFIT and first verified payment, not commits/PR counts.
- A merge is not revenue. Recognize all revenue, including gross revenue, only when payment evidence is VERIFIED. Pending receipts are separate.
- Safe, economically rational, authorized, verifiable actions only. No hidden security bypass, host access, secret leakage, fake API successes or fake reward confirmations.
- Master controls state; specialized scout, evaluator, researcher, coder, tester, security reviewer, code reviewer, PR manager, outcome tracker, payment tracker, finance and learning roles.
- ASSISTED default. Observe permits discovery/evaluation only. Autonomous submissions deferred and never unrestricted by default.
- Preserve existing authentication and data; inspect before non-destructive migration. No production repository operations during acceptance testing.
